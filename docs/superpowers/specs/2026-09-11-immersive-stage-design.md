# 沉浸式采诗台 · 设计稿（v1.1）

> 状态：设计已确认（2026-09-11）｜ 分支：`feat/immersive-stage`
> 定位：**A — 漂亮的自动化录制工具**
> 关联：[DESIGN.md](../../../DESIGN.md)、[ROADMAP.md](../../ROADMAP.md)（v1.1 #14–#18）

## 1. 背景与目标

DESIGN.md 把「封面即氛围」「活的界面」写成设计原则，代码里只兑现了个意思（`RecordView.artColor` 是按 `track.key` 哈希进三色表，与封面无关）。本设计把 v1.1 的 #14–#18 合并为**一次统一的视觉重做**：把「采诗」从功能页变成舞台。

成功标准：打开 App 进入采诗台，一眼能认出这是乐府；录制中的界面像 Apple Music 的正在播放一样有氛围，且不牺牲 v1.0.1 以来的性能修复。

## 2. 范围

### In

- #14 封面取色 + 全窗封面氛围背景
- #15 歌词升级（整行滚动优先，KRC 逐字为增强）
- #16 府库轻量版（封面墙 + Quick Look）
- #17 视觉层次（材质 / 空态 / 对比度）
- #18 动效收口 + 完成通知 / 触感
- 纳入金点子：真实波形、封卷仪式、菜单栏封面、主题扩展（封面主题 + 纸墨主题）

### Out（归入定位 B，另版）

元数据编辑、命名模板、批量转换、分享卡、采诗年鉴、ShazamKit 识别、完整播放器 / 歌单、多音源。

## 3. 视觉系统（#14 + #17）

**氛围背景**：当前封面高斯模糊铺满全窗 + 多层渐变遮罩（中央亮、四周沉）；前景卡片以材质压住，保证可读。

**取色管线（确定性）**：降采样 → 提主色 → 亮度 / 饱和度钳制 → 深浅主题各派生一套 token。灰阶 / 低饱和封面回落默认粉。按 `track.key` 缓存，异步提取，不占主线程。

**切歌**：背景交叉淡入，非硬切。

**对比度**：正文 ≥ 4.5:1、辅助文字 ≥ 3:1；accent 只用于大块氛围与装饰，不单独承载小字。

## 4. 歌词（#15 + #18）

- 第一阶段：整行滚动 + 0.3s 上移过渡（所有歌词源通用）。
- 第二阶段：保留汽水 KRC 的词段时间轴，做逐字高亮（仅汽水本地源；作为增强，不阻塞兜底）。
- 进度基准：用采集端样点计数，而非墙钟，减少漂移。

## 5. 实时与出片（#18）

- **真实波形**：替换现 `MeterWave` 的伪随机柱，接真实电平历史（环形缓冲，CA 层直驱，不进 SwiftUI 视图图）。
- **封卷仪式**：收卷按钮进度态 → 封卷动效 → 系统通知（带封面）→ 触感反馈。
- 菜单栏迷你控制台加封面缩略。

## 6. 府库轻量版（#16）

- 按日期 / 专辑分组的封面墙；悬停轻预览；空格 Quick Look；右键（在访达显示 / 重裁）。
- 不做完整播放器与队列（留待定位 B）。

## 7. 组件与落点

| 组件 | 职责 |
|---|---|
| ArtworkColorService | 封面 → 主色 → 双主题 token，带缓存 |
| AmbientBackground | 模糊封面 + 遮罩，交叉淡入，CA 驱动 |
| LefuTheme 扩展 | 运行时 accent 派生，保证两主题对比度 |
| LyricsModel | 支持词段时间轴，兼容 LRC |
| MeterWave | 真实电平历史 |
| LibraryGrid | 轻量封面墙，复用 CoverExtractor |

## 8. 里程碑（5 个可独立验收的提交）

2. 歌词升级（#15）
3. 真实波形 + 封卷仪式（#18）
4. 视觉层次（#17）

## 9. 验收

- 纯函数单测：取色钳制、歌词解析（需补最小 test target）。
- 手动验收清单：待机 / 采录中 / 收卷 / 完成 四态截图对照 DESIGN token；深浅双主题各过一遍对比度。
- 性能：录制 30 分钟，主线程占用不得回到 v1.0.1 的病态水平。

## 10. 风险与取舍

- 氛围背景若用 SwiftUI 全树重绘会退回性能病 → 一律 CA 层直驱。
- 逐字高亮依赖更稳时钟，若达不到则只交付整行滚动，逐字保持关闭。
- 取色对浅色低饱和封面易发灰 → 钳制 + 回落规则兜底。
